# 官方提交要求

来源：https://www.heywhale.com/org/cunsl/competition/area/6aba38446e5beff2fca62136/content/3

## 一、提交方式

1. **初赛阶段**：参赛者将预测结果以单个JSON文件格式（`result.json`）提交到平台，平台进行在线评分，实时排名。以截止日期排名决出入围复赛的队伍。
2. **复赛阶段**：提交要求与初赛一致，以截止日排名决出入围决赛的队伍。
3. **决赛阶段**：入围决赛团队提交决赛评审资料，并前往线下专家评审会进行现场答辩。
4. **复现阶段**：参赛者提交复现算法所需要的各类文档、源代码等资料，主办方进行复现审核。

## 二、提交注意事项

1. 在线评估提交限制：每个参赛团队每天最多提交3次作品文件进行在线评测，若新提交结果好于之前提交结果，排行榜中的成绩将自动进行更新覆盖；
2. 公平竞争，遵守规则，尊重对手，提交的json文件禁止通过手动打标获得，严禁直接非开源模型（如ChatGPT）直接预测；
3. 提交的算法必须能够复现，否则将取消参赛者排名资格；
4. 决赛提交的算法所需文档中需注明复现算法步骤。

## 三、提交示例

参赛选手将测试集结果以UTF-8编码格式保存为JSON文件，命名为`result.json`，包含每个问题的ID（ID一定要和原数据集中保持一致）、对应数据源及最终生成的查询语句。

**样例格式如下：**

```json
[
  {
    "question_id": 1,
    "db": "MYSQL",
    "query": "select count(*) from ……'"
  },
  {
    "question_id": 2,
	 ……
  },
  {
    "question_id": XX,
    "db1": "MYSQL",
    "query1": "select count(*) from ……",
    "db2": "POSTGRESQL",
    "query2": "select count(*) from XX where XX in（result）……"
  }
]
```

*注：本赛题涉及的跨数据源查询需要先后查询两个数据库系统，在第二个查询指令中以 `result` 代替第一个查询指令的执行结果。*
