# 已知错误修复与回归验证

本次修复针对生成流程及保守校验规则，未添加embedding。未将验证答案作为检索示例或提示词输入，也未手工改写模型查询。

## 已实现

- ES提示与检索示例统一使用原生JSON对象，模型响应由程序编码为官方字符串；保留旧字符串兼容性。屏蔽结构不合法的ES训练示例，防止模型学到错误的query/aggs层级。原始训练文件未改写。
- 生成约束明确总销量的两层聚合、每层结果粒度及所需返回列；总销量问题按单笔qty排序会触发修复。此规则有意只覆盖明确的总销量排名表述，不是完整SQL语义判定。
- 区分AIS时段内MAX(sog)与基础信息中的额定max_speed，避免错误引入MySQL。
- 跨源补充属性时保留mmsi、所需属性；查询AIS记录时保留记录粒度。
- 同源多问句合成一条SQL；校验拒绝同源伪跨源、第一阶段引用result，以及仅在字符串中出现result的假依赖。
- 每次请求加入由当前问题生成的requirements，规则不依赖问题编号或验证答案。
- 新增--ids参数用于定向回归；代码指纹包含规则与检索模块，避免复用旧配置的缓存。
