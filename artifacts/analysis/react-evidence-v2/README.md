# ReAct v2 外部知识注入核对

本次直接比较原始/处理后资料，并核对全部5,830道训练题、400道测试题的首轮提示词。另用DeepSeek Flash关闭思考模式实测此前7题，调用35次，未按题号修改召回逻辑或SQL。旧模型结果保留在原目录。

## 资料核对

| 类型 | 原始与处理后差异 | 新流程处理 |
|---|---|---|
| 训练案例 | 5,830→5,605，225个原始记录未进入clean，另20个保留记录的标注有修订 | 原始记录全部保留；21条修订及2条排除标记均单独说明；冲突不当作正确答案 |
| 知识 | 1,800条均在，7条正文被替换 | 原文与修订同时保留 |
| Schema | 265个表/索引均在，但46条表注释缺失；中文列注释通常仍在 | 保留完整表段、表前说明、表后选项和原始注释，参与检索并返回模型 |
| 字典 | 344条INSERT逐条比较，统一换行后内容一致 | 直接从原文件读取；无需声称这部分存在丢失 |
| 参考说明 | 2个原始说明文本未进入旧Context | 保留并允许工具返回完整说明 |

46条表注释查询的目标表首位召回由31/46提升为46/46，Top-5由44/46提升为46/46。该结果是按注释文本查询Schema的召回检查，不等同于全部业务自然语言问题的召回率。

## 工具流程

必备顺序：search_examples → get_schema → search_knowledge → check_query → finish。首轮案例用于展示已有精确证据；示例工具补充候选，Schema工具核对真实结构，知识检索以已核对的源库为范围。任何证据检索使上次成功检查失效；新表或再次检索示例要求刷新知识，finish只能提交最近成功检查的候选。
